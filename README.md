# TicketFlow 🎫

TicketFlow is a full-stack IT support and ticket management system built with the MERN stack.

## 🚀 Features

- Admin registration and login
- Employee authentication
- Workspace management
- Employee management
- Join request system
- Create and manage support tickets
- Ticket details and status management
- Admin dashboard
- Secure authentication using JWT and cookies
- MongoDB database

## 🛠️ Tech Stack

### Frontend
- React
- Axios
- React Router
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- Cookie Parser

### Deployment
- Render
- MongoDB Atlas
